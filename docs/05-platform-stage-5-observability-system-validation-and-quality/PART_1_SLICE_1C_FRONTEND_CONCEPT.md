# Stage 5 第一部分 Slice 1C 前端概念

状态：已接受（2026-07-28）

日期：2026-07-28

## 1. 信息架构

沿用 Workspace“运行记录”入口，以 Tab 区分两个只读视图：

```text
Workspace
  └─ 运行记录
       ├─ Tab：运行记录
       │    └─ Slice 1A 既有列表与详情
       └─ Tab：质量与成本
            ├─ 时间与范围筛选
            ├─ 运行健康
            ├─ Provider 用量与计算成本
            ├─ 失败分类
            └─ 最近异常运行与下钻
```

默认进入“运行记录”，避免改变既有用户路径。Tab 使用可访问的 tabs 语义，并
保留当前 Workspace；不新增顶级导航或营销式 dashboard。

## 2. 页面层级

### 筛选栏

- 时间：24 小时、7 天、30 天 segmented control；
- 业务类型、角色、状态：紧凑 select；
- 刷新：图标按钮，带 tooltip 和 `aria-label`。

筛选改变后整体重新读取摘要和最近异常运行。筛选值在两个数据区域保持一致，
不得出现“顶部是 7 天、列表仍是 24 小时”的静默漂移。

### 运行健康

使用一条紧凑指标带显示：

- 总运行数；
- 成功、失败、取消、进行中数量；
- P50/P95 duration；
- duration 样本数。

状态必须有文字，不只依赖颜色。无 duration 样本显示“暂无样本”，不显示 0 ms。

### Provider 用量与计算成本

使用一条指标带和一行完整性说明：

- Provider 调用数；
- input/output token；
- 已知人民币计算成本；
- 成本已计算调用数；
- 成本未知调用数；
- 无外部计费事实的 Run 数。

金额统一显示 `¥` 和人民币文案。`known_amount=0` 但存在 unknown 或无计费事实
时，必须显示对应数量，不能呈现“总成本 0 元”这一误导结论。

### 失败分类

使用按数量降序的紧凑列表或水平条，不使用饼图。每行显示安全错误标签、数量和
“查看运行”动作。未知映射显示“其他运行问题”，不得展示原始异常。

### 最近异常运行

复用 Slice 1A Run 行和安全详情模式，只列当前筛选范围内的 failed/canceled
运行。点击后可查看 Tool Call；存在 AgentRun owner Provider Call 时提供
“查看模型调用”命令，读取 Slice 1B API。

Provider Call 详情显示 phase、状态、provider/model、usage、latency、稳定错误码
和计算成本，不显示 prompt、回答、raw response 或价格快照。

## 3. 状态矩阵

| 状态 | 摘要区域 | 异常运行 | 用户动作 |
|---|---|---|---|
| 初始 loading | 保留稳定高度的 skeleton/status | 保留列表高度 | 等待或切换 Tab |
| ready / 有数据 | 显示指标与分类 | 显示异常运行 | 筛选、下钻、刷新 |
| ready / 全空 | 显示“当前范围暂无运行” | 空 | 调整时间或筛选 |
| ready / 无失败 | 正常显示健康和成本 | “当前范围暂无异常运行” | 查看运行记录 |
| 部分成本未知 | 已知金额与未知数并列 | 正常 | 下钻核对调用 |
| 全部成本未知 | 金额显示“暂无可计算金额” | 正常 | 查看 unknown reason |
| 无 Provider Call | 显示“无外部计费事实”数量 | 正常 | 查看 Run |
| duration 无样本 | P50/P95 显示“暂无样本” | 正常 | 查看进行中 Run |
| 摘要 error | 安全错误，保留筛选 | 不冒充空数据 | 重试 |
| 异常列表 error | 摘要仍可用 | 当前区域安全错误 | 单独重试 |
| Provider 下钻 loading | 背景页面保持稳定 | 详情加载 | 等待或关闭 |
| Provider 下钻 error | 背景页面保持稳定 | 安全错误 | 重试或关闭 |
| 未知 role/error | 计入总数/其他分类 | 安全降级文案 | 查看安全详情 |

不同请求部分失败时保留已成功区域，不清空整个页面，也不把失败投影为空数据。

## 4. 响应式矩阵

| 视口 | 布局 |
|---|---|
| 桌面 `>= 1024px` | 筛选单行或稳定换行；指标带横向分组；错误分类与异常运行上下排列 |
| 中等 `768-1023px` | 筛选两行；指标使用 2-3 列网格；列表保持状态可见 |
| 移动 `< 768px` | Tab 可完整读取；筛选纵向；指标两列/单列；详情全宽 |

共同要求：

- 指标区使用全宽 band 或无框网格，不嵌套卡片；
- 固定最小列宽，数字、人民币金额和长错误标签不能相互覆盖；
- 不按视口宽度缩放字体；
- 页面不产生横向滚动；
- 长标签换行或省略，并提供可访问的完整名称；
- loading、筛选和异步详情不得造成页面大幅跳动。

## 5. 交互与可访问性

- Tab 支持键盘操作、可见 focus 和正确 `aria-selected`/关联 panel；
- segmented control 与 select 有可访问名称；
- 刷新和下钻图标使用现有图标库并提供 tooltip；
- loading 使用 `role=status`，错误使用 `role=alert`；
- 自动刷新不在本 Slice 默认开启，避免额外查询和焦点扰动；
- 状态、成本完整性和错误类别均使用文字，不只依赖颜色；
- 下钻关闭后焦点返回触发位置；
- 筛选不会因请求失败或切换详情而重置。

## 6. 文案原则

- 页面标题使用“质量与成本”，辅助区域明确“运行健康”和“人民币计算成本”；
- 不把 `succeeded` 写成“回答正确”或“质量优秀”；
- 不把 known amount 写成 provider 账单；
- unknown 使用“成本未知”，无 Provider Call 使用“无外部计费事实”；
- 未知异常不展示内部 error code 原文，使用安全中文标签；
- 页面不放操作教程、功能说明或键盘快捷键说明。

## 7. 明确不做

- 顶级导航、首页 hero、装饰性图表或卡片墙；
- 趋势折线、饼图、provider/model 排行；
- 质量评分、正确率或学习效果结论；
- 价格编辑、预算、账单、导出；
- Run/Provider Call 的重试、取消或删除；
- RAG Answer/workspace-only Provider Call 聚合；
- prompt、回答、答案、代码、日志或 raw response 查看器。

## 8. 人工 Gate

本概念与 Spec 005 已于 2026-07-28 一并通过人工 Gate。实现者不得自行增加
图表、管理动作、聚合维度或质量分数。
