# Stage 5 第一部分 Slice 1A 前端概念

状态：已于 2026-07-27 通过人工 Gate

日期：2026-07-27

## 1. 信息架构

Slice 1A 沿用现有 Workspace“运行记录”入口，不新增 Quality & Cost 页面，也不
重新设计主导航：

```text
Workspace
  └─ 运行记录
       ├─ 筛选栏：课程 / 角色 / 状态
       ├─ 最近 Run 列表
       │    ├─ 业务身份
       │    ├─ 角色 / attempt
       │    ├─ token / 时间 / duration
       │    └─ 状态
       └─ 行内展开详情
            ├─ 安全错误说明
            └─ 有序 Tool Call 阶段
```

页面责任仍是只读诊断。重试、取消、删除和重新运行继续由 Course、Tutor、
Practice 或 Code Lab 业务页面负责。

## 2. 列表信息层级

每条 Run 保持稳定的三组信息：

1. **身份**：业务类型、课程和课节；Code Lab 可显示语言。
2. **用量与时间**：input/output token、创建时间和 duration。
3. **状态**：进行中、成功、失败或取消。

列表不加入金额、provider/model、质量分数或大段说明。Slice 1C 再评审聚合
质量/成本信息，避免 Slice 1A 同时承担 dashboard 风险。

## 3. 角色与身份文案

| Role | 中文角色 | 默认业务身份 |
|---|---|---|
| `course_architect` | 课程架构 | 课程大纲 · 课程 |
| `lesson_writer` | 课节撰写 | 课节草稿 · 课程 · 课节 |
| `tutor` | 辅导 | 本课辅导/本课程辅导 · 课程 · 课节 |
| `exercise_author` | 练习生成 | 练习生成 · 课程 · 课节 |
| `answer_grader` | 练习评分 | 练习评分 · 课程 · 课节 |
| `scientific_solution_grader` | 科学题验证 | 科学题验证 · 课程 · 课节 |
| `code_execution` | 代码执行 | 代码执行 · 语言 · 可用课程/课节 |
| 未知值 | 其他运行 | 其他运行 · 安全 role 值 |

未知 role 的原始值只作为短小的稳定标识显示，不解释、不转换为内部错误，也不
显示空标签。

## 4. 筛选

筛选栏保持三项，不新增高级搜索：

- 课程：全部课程或当前 Workspace active Course；
- 角色：全部角色和七种已知 role；
- 状态：全部、进行中、成功、失败、已取消。

窄视口允许筛选换行或纵向排列，不能压缩选项文本、覆盖刷新按钮或产生横向
页面滚动。筛选课程读取失败时，角色/状态和运行列表仍可使用。

## 5. 展开详情

- 点击列表行展开当前 Run 的 Tool Call。
- 同时只展开一条，避免长列表失去扫描性。
- 每个阶段显示 ordinal、中文/安全 Tool 名、状态、结果数量和 latency。
- 未知 Tool 显示其稳定 name；不得显示 input hash、参数或 raw output。
- 单条详情失败只影响当前展开区域，列表和其他 Run 保持可用。
- 运行中 Run 每 2 秒刷新现有列表/详情；终态后停止轮询。

## 6. 状态矩阵

| 状态 | 列表 | 展开详情 | 用户动作 |
|---|---|---|---|
| 初始 loading | 保留稳定高度的加载状态 | 不展开 | 等待或离开 |
| ready / 有数据 | 显示最近 Run | 按需加载 | 筛选、展开、刷新 |
| ready / 空 | 显示当前筛选无记录 | 无 | 调整筛选、刷新 |
| 列表 error | 显示安全错误 | 无 | 重试 |
| 详情 loading | 列表保持可用 | 当前行显示加载 | 等待或收起 |
| 详情 error | 列表保持可用 | 当前行显示安全错误 | 重试展开/刷新 |
| running | duration 显示“进行中” | 显示已提交阶段 | 自动轮询 |
| succeeded | 显示已知 token/duration | 显示成功阶段 | 查看 |
| failed | 显示稳定错误概述 | 显示失败阶段/错误码映射 | 去业务页处理 |
| canceled | 显示已取消 | 显示已提交阶段 | 查看 |
| usage 全缺 | “token 未报告” | 不推断 | 查看 |
| usage 部分缺 | `入 ? / 出 N` 或反向 | 不补估算 | 查看 |
| 已删除 owner | “已删除对象” | 只保留安全阶段 | 查看 |
| 未知 role/kind | “其他运行” | 安全降级 | 查看 |

## 7. 错误文案

- 已知稳定错误码映射为短小、可行动的中文说明。
- 未知错误统一显示“运行出现问题”，不展示内部 exception、provider body 或
  worker 日志。
- 错误码映射缺失不能阻止列表渲染。
- Slice 1A 不在运行记录中提供重试按钮，避免绕过各业务对象的权威状态机。

## 8. 响应式矩阵

| 视口 | 布局 |
|---|---|
| 桌面 `>= 1024px` | 筛选横向排列；Run 行保持身份、指标、状态三组；详情横向扫描 |
| 中等 `768-1023px` | 筛选允许换行；Run 指标移动到身份下方；状态保持可见 |
| 移动 `< 768px` | 筛选纵向；Run 信息纵向分组；展开详情改为紧凑两列/单列 |

共同要求：

- 课程、课节和未知 role 长文本可换行或省略，并通过 title/可访问名称读取完整
  内容；
- 不缩放字体适配视口；
- 状态、展开图标和刷新按钮不被长文本挤出；
- Tool name、结果数量、latency 和错误说明不重叠；
- 页面纵向可滚动，不制造不可控横向滚动。

## 9. 可访问性与交互

- 刷新、展开/收起继续使用图标与明确 `aria-label`/tooltip。
- 整行按钮保留清晰 focus 状态。
- loading 使用 `role=status`，读取失败使用 `role=alert`。
- 状态不能只依赖颜色；必须保留文字。
- 展开状态使用 `aria-expanded`，详情区域与触发器建立关联。
- 自动轮询不得抢夺焦点、折叠用户当前详情或重置筛选。

## 10. 明确不做

- 新导航或独立 Quality & Cost dashboard；
- 金额、provider/model、趋势图、成本图表；
- 日志、prompt、evidence、答案或代码查看器；
- 列表内重试、取消、删除或批量操作；
- 任意卡片嵌套或营销式页面改造；
- 为未知 role 猜测对应业务。
